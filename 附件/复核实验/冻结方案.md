# v2 训练选型与封存验收协议

本实验使用同一发布阈值 0.04 AU。40 条新合成光强扫描入组前锁定观测位置、划分方法、评分和宽度网格。每条 181 点中封存第 35–52 与 105–122 格（从 0 计），145 个训练点交给拟合程序，36 个保留点和几何真值另存。条件与器件标签不出现在训练文件名中。

盲拟合阶段临时目录只放匿名训练 CSV 和 blind_fit.py，在该目录运行拟合，记录输出 SHA-256。再开启封存的 test 与 truth，计算各策略的 RMSE 和几何恢复率。分盲是公开、可审计的计算流程，样本均为原创合成观测；没有第三方受试者或真实光学平台参与。

比较三条策略：只用常量背景的 v1；依据两类背景的训练 SSE 直接选复杂度的无惩罚对照；对新增斜率施加 ln(145) 惩罚的 v2。v2 对每种背景独立完整搜索单缝和双缝几何，以 n·ln(SSE/n)+I(线性)·ln(n) 选背景。仅在训练的最佳两模型之间比较附加斜率，相同的几何搜索范围沿用原程序。此为背景自由度的相对信息准则，不赋予模型正确概率。

主要终点为通过阈值且器件类别正确、宽偏差 ≤2 μm、双缝间距偏差 ≤5 μm 的扫描数；并报拒绝、错误通过、线性背景选中数及保留 RMSE 中位数。固定种子改变网格外几何、噪声、线性与弯曲背景，并加入训练范围以外的局部眩光失配。分母每组为 8。宽松的固定阈值和已知轴、波长、屏距是合成实验的假设。
