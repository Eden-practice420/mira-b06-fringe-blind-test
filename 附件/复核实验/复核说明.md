# 复核实验 v2 · 背景选型盲测

v2 将训练与揭封分成两个程序。新扫描的线性背景组正确交付从 0/8 增至 8/8，封存 RMSE 中位数由 0.1930 降至 0.0133 AU。常背景组避免 8 次多余斜率；弯曲、高噪、局部眩光的 24 条仍全部拒报。

在当前目录执行下列命令。CPython 3.11，仅需标准库。请在第二条结束时先保留预测摘要，再运行第三条。

```powershell
python -X utf8 prepare.py
python -X utf8 lock_training.py
python -X utf8 reveal.py
```

训练集在 training，封存观测和真值在 sealed，拟合冻结产物是 predictions.json 与 predictions.sha256；逐点残差为 heldout_residuals.csv，汇总和逐条判定为 results.json。详见《冻结方案》。所有新观测均为原创数字模拟，可随作品公开演示和复算。

以 CPython 3.11.9 重建可逐字节复现随包冻结文件。以 CPython 3.12.14 复算时，浮点求和的末位会改变 JSON 与摘要；三种策略的几何选择、背景选择、验收判定及汇总值已交叉核验。摘要用于同一次冻结与揭封之间的完整性核对。
